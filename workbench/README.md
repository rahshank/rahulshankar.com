# Workbench

## Purpose
Hold planning, research, and decision notes for the personal site without crowding the publishing system.

The website itself lives in `source/`, `scripts/`, `raw/`, and generated output folders. This folder is for the thinking around it.

## Folder map
| Path | Role | Status |
| --- | --- | --- |
| `planning/` | Architecture, deployment, migration, and launch notes | working |
| `research/` | Inspiration, homepage intro, visual direction, and reference-site notes | working |
| `experiments/` | Site implementation experiments and prototypes before they settle into `source/` | working |
