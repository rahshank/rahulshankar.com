# Pinterest Captures

## Purpose
Store local captures of Pinterest boards that require Rahul's logged-in browser.

## Folder Map
| Path | Role | Status |
| --- | --- | --- |
| `ddc-ghosts-of-bombay/` | Complete-page capture of the DDC / Ghosts of Bombay inspiration board | pending |

## Capture Pattern
Open the board in a logged-in browser, scroll until the pins are loaded, then save the page as `Webpage, Complete` into the board folder. Codex can inspect the saved HTML and image assets from there.
