# rahulshankar.com

Source and generated static files for https://rahulshankar.com.

This is a small custom static site published with GitHub Pages. The repo keeps editable source files and generated Pages output together so the live site can be rebuilt from the same place.

## Repository Map

| Path | Role |
| --- | --- |
| `source/` | Editable site content, templates, styles, and assets. |
| `scripts/` | Build and site-check helpers. |
| `docs/` | Generated GitHub Pages output served at `rahulshankar.com`. |

Private planning, drafts, raw imports, and local experiments live outside this public repo.
